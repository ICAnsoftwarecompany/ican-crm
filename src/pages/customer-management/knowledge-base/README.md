# Customer Management Knowledge Base Pages

Route-page components for the shared Customer Hub knowledge base live here. Knowledge behavior,
article editing, and API access remain in `src/features/service`.

- `ServiceKnowledgePage.jsx`: knowledge list at `/customer-management/tickets/knowledge` and
  `/customer-management/service/knowledge`.
- `ServiceKnowledgeArticlePage.jsx`: article editor at `/customer-management/tickets/knowledge/:articleId`
  and `/customer-management/service/knowledge/:articleId`.
