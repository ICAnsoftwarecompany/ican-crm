# bulk-actions

هذا الفولدر يحتوي شريط الإجراءات الذي يظهر أعلى جدول مركز العملاء المحتملين عند تحديد صف أو أكثر، ومعه كل المكونات التابعة له: أزرار التحديد، التثبيت، تغيير الحالة، تغيير التاج، إضافة متابعة، وإرسال الرسائل عبر القنوات الاجتماعية.

تم تجميع هذه الأجزاء هنا حتى يكون شريط الإجراءات بالكامل في مكان واحد، ويسهل تطويره بدون تضخيم ملف `CustomersPage.jsx`.

## الهيكل

```text
bulk-actions/
  CustomersBulkActions.jsx
  SelectedCountBadge.jsx
  PinBulkActionsButton.jsx
  selection-actions/
  social-messaging/
  index.js
```

## الملفات الرئيسية

- `CustomersBulkActions.jsx`: المكون الجامع للشريط، ويقرأ الصفوف المحددة ويدير فتح مودال الرسائل.
- `SelectedCountBadge.jsx`: شارة عدد العملاء المحددين.
- `PinBulkActionsButton.jsx`: زر خيارات التثبيت. يفتح قائمة فوق كل الطبقات لاختيار: بدون تثبيت، تثبيت أفقي أعلى الصفحة، أو تثبيت رأسي في rail بجوار القائمة الجانبية.
- `selection-actions/`: إجراءات تعمل على التحديد الحالي مثل إضافة متابعة، تغيير الحالة، تغيير التاج، والسوشيال أكشن.
- `social-messaging/`: مكونات قنوات الرسائل ومودال كتابة الرسالة وتجهيز بيانات الإرسال.
- `index.js`: نقطة تصدير موحدة للفولدر.

## طريقة العمل

1. `DataTable` يرسل الصفوف المحددة إلى `CustomersBulkActions`.
2. الشريط يعرض عدد الصفوف المحددة ويتيح اختيار مكان تثبيته.
3. إجراءات التحديد تأتي من `selection-actions/`.
4. عند الضغط على قناة اجتماعية، يتم فتح `social-messaging/CustomerSocialMessagingPanel.jsx`.
5. زر إضافة متابعة لا يعمل إلا عند تحديد عميل محتمل واحد فقط.

## أوضاع التثبيت

- الوضع العادي: يظهر الشريط داخل Toolbar الخاص بالجدول.
- التثبيت الأفقي: يظهر الشريط أعلى الصفحة بنفس تصميمه العريض.
- التثبيت الرأسي: يتم نقل الشريط إلى rail مستقل بجوار `CustomersSidebar` ويدفع مساحة الجدول بدلا من الظهور فوقه. عرض الـ rail صغير ومخصص للإجراءات السريعة.

يتم حفظ اختيار المستخدم في `localStorage` بالمفتاح:

```text
customers-bulk-actions-pin-mode
```

يوجد ملف توافق خارجي في:

```text
src/pages/customers/components/CustomerSocialMessagingPanel.jsx
```

هذا الملف يعيد التصدير من المسار الجديد حتى لا تنكسر أي استدعاءات قديمة.
