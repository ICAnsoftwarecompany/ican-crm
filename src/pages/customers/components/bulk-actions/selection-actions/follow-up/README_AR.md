# follow-up

هذا الفولدر يحتوي إجراء إضافة متابعة من شريط الإجراءات الجماعية في صفحة مركز العملاء المحتملين.

## الملفات

- `AddFollowUpBulkAction.jsx`: زر صغير يظهر داخل شريط الإجراءات عند تحديد صف واحد فقط. عند الضغط عليه يستدعي من الصفحة ديالوج إضافة المتابعة المشترك.

## العلاقة مع الديالوج

الزر لا يحتوي منطق حفظ الملاحظة. منطق الفورم، الإرسال إلى `saveAction`، وخيار تغيير الحالة موجود في:

`src/pages/customers/components/follow-up-note/FollowUpNoteDialog.jsx`

بهذا الشكل أي مكان في النظام يحتاج إضافة متابعة يمكنه استخدام نفس الديالوج بدون تكرار.
