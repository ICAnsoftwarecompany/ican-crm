# فولدر أنشطة العملاء

هذا الفولدر خاص بصفحة إجراءات المكالمات والاجتماعات داخل قسم العملاء المحتملين.

## المسار

الصفحة تظهر من sidebar العملاء على:

```text
/LeadsCenter/activities
```

## لماذا يوجد هذا الفولدر؟

منطق الأنشطة نفسه موجود في:

```text
src/features/activities/
```

أما هذا الفولدر فهو طبقة صفحة داخل:

```text
src/pages/customers/pages/activities/
```

حتى تبقى صفحات مركز العملاء مرتبة، ويكون من السهل لاحقا تخصيص عرض الأنشطة داخل قسم العملاء بدون لمس الموديول العام.

## الملفات

- `CustomerActivitiesPage.jsx`: يستدعي صفحة الأنشطة الموحدة.
- `index.js`: export للصفحة.
- `README_AR.md`: شرح دور الفولدر.

## ملاحظة معمارية

المكالمات والاجتماعات لا يتم فصلهم في موديولين مختلفين. كلاهما يستخدم موديول موحد:

```text
features/activities
```

والفرق بينهم يتم من خلال الحقل:

```json
{
  "type": "call"
}
```

أو:

```json
{
  "type": "meeting"
}
```
