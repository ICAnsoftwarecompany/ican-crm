## الراوت والاستخدام

`/customers/:customerId/deals`

مثال: `/customers/1/deals` يعرض كل صفقات العميل 1.
`/customers/1/deals?deal=5` يفتح تفاصيل الصفقة 5 تلقائيًا.
استخدم معرف العميل وليس معرف الليد أو معرف ارتباطه بالصفقة.
المسار داخل Layout التطبيق وحماية تسجيل الدخول ويدعم الفتح المباشر والريفريش.

لإعادة الاستخدام استورد `customerDealsPath` من `features/customers`:

```js
navigate(customerDealsPath(customer.id, dealId))
```

## البيانات والمكونات

`CustomerDealsPage.jsx` يقرأ بارامترات الراوت ويستدعي `CustomerDealsWorkspace` فقط.
المنطق والمكونات في `src/features/customers/customer-deals/`، وملف README هناك يشرح مسؤولياتها.
المصدر: `GET /api/tenant/customers/{customerId}/deals` عبر httpClient للمصادقة.

تعرض الصفحة بيانات العميل، ملخص الصفقات، كل الديلات بما فيها Lead-Center،
المنتجات المباعة، العقود، طريقة الدفع، الدفعة المقدمة، خطة الأقساط ومواعيدها والمدفوع منها.
يوجد بحث باسم الصفقة أو رقم العقد وتصفية بالحالة وحالات تحميل وفشل وفراغ.
القيم المالية من المعاملة وليست سعر المنتج الحالي، دون افتراض عملة غير موجودة في البيانات.
تستخدم الواجهة متغيرات الثيم وتدعم العربية والإنجليزية واتجاه اللغة.
