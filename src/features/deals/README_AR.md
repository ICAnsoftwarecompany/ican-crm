# وحدة Deals Workspace

تحتوي هذه الوحدة حاليًا على طبقة الاتصال بالدوال الواردة في مجموعة Postman الخاصة بـ Deals Workspace.

## ملفات API

- `api/pipelineTemplatesApi.js`: عرض وإنشاء وتعديل وحذف قوالب مسار البيع ومراحله.
- `api/dealsApi.js`: CRUD للصفقات.
- `api/dealResourcesApi.js`: فريق الصفقة ومنتجاتها.
- `api/dealLeadsApi.js`: إضافة الليدز، إنشاؤهم، التوزيع الجماعي، عرض ليدز الصفقة، تغيير المرحلة ومزامنة المنتجات.

يضيف `httpClient` كلمة مرور الـ API والتوكين تلقائيًا، ولذلك لا تكررها هذه الدوال.

## ملاحظات العقد الحالي

- التعديل في القوالب والصفقات يستخدم `POST` كما هو موضح في Postman.
- مسار جلب منتجات Deal Lead مكتوب في العقد الحالي `productsc` وتم الاحتفاظ به حرفيًا لحين تصحيحه من الباك إند.
- مجموعة Postman الحالية لا تتضمن دوال Won/Lost أو العقود أو التحليلات؛ لا يجب افتراض مسارات لها قبل توفير العقد.

## Pipeline Board

المكوّن العام موجود في `src/shared/components/pipeline-board/` ويدعم مراحل ديناميكية وswimlanes والسحب بين المراحل. المراحل النهائية لا تنفذ تغيير المرحلة مباشرة، بل تستدعي `onTerminalStageDrop` حتى يؤكد المستخدم عملية الربح أو الخسارة من التدفق المخصص.

## الصفحات والمسارات

- `/deals`: مركز الصفقات المبني على `DataTable` مع البحث والفلترة والتصدير وإنشاء صفقة جديدة.
- `/deals/:dealId`: مساحة الصفقة الواحدة.
- يتم حفظ وضع العرض `kanban | table` في `localStorage` بالمفتاح `deal-workspace:view-mode`.
- وضع Kanban يعرض التابات أعلى الصفحة، ووضع Table يعرض نفس الأقسام داخل sidebar قابل للطي.
- زر Workflow يستخدم `WorkflowLauncher` المشترك بسياق `module: deals`.
- زر مساعد الصفقة يستخدم مكوّن `AgentChat` الحالي داخل `AppDrawer`.
- زر التقويم يفتح صفحة التقويم المشتركة الحالية.

## عرض البيانات

- مراحل اللوحة تأتي من `pipeline_template.stages` ولا توجد مراحل ثابتة داخل الواجهة.
- الجدول واللوحة يقرآن نفس قائمة Deal Leads.
- الفريق والمنتجات يعرضان البيانات القادمة من endpoints الخاصة بالصفقة.
- العقود والتحليلات تعرض حالة عدم توفر واضحة، لأن مجموعة Postman الحالية لا تحتوي API لهما.

## الترجمة والثيم

- النصوص موجودة في `src/locales/{ar,en}/dealWorkspace.js` ومسجلة في ملفات اللغات.
- الأسطح والنصوص والحدود تعتمد على متغيرات الثيم، وتعمل في الوضعين الفاتح والداكن.
- تمت إضافة الصفقات إلى قسم المبيعات في الـ sidebar الرئيسي.
